Four tables and two notes. B. Apply-time failures, and which are knowable in advance

The accept path can produce 25 distinct failures, drawn from reconciliation.ts, draft-projector.ts and storage.ts. A client could check a selection for 14 of them before submitting anything. The package's own projector answers those questions, so a preflight built on it reports the behaviour the apply path will actually take rather than a second implementation that drifts from it.

C. Naming

The corpus is a private roleplay, so every character and scene name carries one consistent neutral alias throughout, and raw chat identifiers drop out rather than receiving an alias. Counts, identifier shapes and mechanics stand unchanged, because those carry the evidence. Citations name a file and a symbol instead of a line number, since line numbers rot across releases and a maintainer reading this later would land somewhere unrelated. Error strings appear verbatim, because those stay greppable.

D. Reproducing this

Anyone can see this for themselves with four pieces: a local Engine instance, a mock model provider standing in for a real one so the run needs no API key, the installed Long-Term Memory package, seeded chat content, and a browser driver for the screenshots. Four scripts cover it, each standalone Node ESM talking to the Engine over HTTP.

ScriptWhat it does
start-mock-provider.mjsServes an OpenAI-compatible endpoint answering chat, embedding and model requests, and synthesizes schema-valid replies so structured-output agents reach real UI states.
bootstrap-instance.mjsWrites .env, creates the mock connection and makes it the default, then installs a package.
seed-chat.mjsCreates a character, a chat and its message history through the REST API.
drive-browser.mjsDrives Playwright against a persistent browser profile and captures screenshots.

The two scripts that produced the diagnoses read state and never write it. maridiag.cjs runs a read-only diagnostic sweep, and embprobe.cjs probes the ONNX binding. Those two established the embedding findings and the rejection findings, and neither one changed anything in the vault to do it.
