JOURNEY 1

First run

"I want this character to remember things about me." Switch it on and reach visible proof it worked, without needing to know what a draft is.

Enable in chat settings See what it can learn from now Accept a handful, modes stated Observe it used in a reply
JOURNEY 2

Import and extract

"Read all of this and tell me what you found." Pick the material, say who it is about, run the pass, and read the outcome without opening the review queue to learn what the run cost.

Choose material, counts per kind Set scope, roster checked first Run with reported progress Read kept and dropped
JOURNEY 3

Curate

"There are a thousand of these. Let me work through them in the order that makes sense to me." Compose a cross-section, work it to exhaustion, apply it, compose the next.

Compose a slice from facets Pivot group and sort Edit in place Resolve conflicts Apply with preflight
JOURNEY 4

Browse and correct

"It said something about me that is wrong. Find it and fix it." Locate one stored memory among hundreds, read where it came from, and change it in place.

Filter the vault down Open the memory Correct the claim Resolve a stored conflict
JOURNEY 5

Why didn't it remember

"It knew this yesterday. Why not now?" Read what recall did on a specific turn, then find out which part of the path is broken.

Check the current turn Scroll back through earlier turns Diagnose in one place Act on a named cause
JOURNEY 6

Keep it healthy

"I want this to still work in six months." See pressure building before it becomes a failure, prune what has stopped earning its place, and read vault state in one view.
